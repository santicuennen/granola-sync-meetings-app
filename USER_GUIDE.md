# Meetings Vault - User Guide

## Overview

Meetings Vault is your personal meeting archive that automatically syncs your Granola meetings to the cloud and provides a beautiful web interface to search, view, and review them.

## Features

- 🔒 **Secure Access** - Password-protected web interface
- 🤖 **AI Summaries** - Automatic meeting summaries generated by Granola
- 📝 **Full Transcripts** - Complete transcripts with speaker attribution
- 🔍 **Search** - Find meetings by title, attendees, or content
- 📅 **Timeline** - Browse meetings by date
- ☁️ **Cloud Sync** - Automatic hourly sync to AWS S3

## Accessing Your Meetings

### Web Interface

1. Navigate to your Vercel URL
2. Enter your password when prompted
3. Browse your meetings in the dashboard

### Login Credentials

- **URL**: Your Vercel deployment URL
- **Password**: Configured in Vercel environment variables

## Using the Dashboard

### Main View

The dashboard shows all your meetings in a list format:

- **Left Panel**: List of meetings with titles, dates, and preview
- **Right Panel**: Detailed view of selected meeting

### Meeting Details

When you select a meeting, you'll see:

- **Title** - Meeting name
- **Date & Time** - When the meeting occurred
- **Attendees** - Who participated
- **AI Summary** - Key points and action items (if available)
- **Tags** - Categories and topics
- **Full Transcript** - Complete conversation with timestamps

### Search

Use the search bar at the top to find meetings by:

- Meeting title
- Attendee names
- Summary content
- Topics discussed

### View Transcript

Click "View Full Transcript" to see:

- Complete conversation
- Speaker attribution (You vs Them)
- Timestamps for each segment
- Formatted for easy reading

## Data Sync

### Automatic Sync

Your meetings sync automatically:

- **Every hour** - Captures recent meetings
- **At Windows startup** - Ensures data is current
- **Background process** - No action needed

### What Gets Synced

Each meeting includes:

- Title and date
- Attendee information
- AI-generated summary (HTML + text + bullets)
- Full transcript with speaker attribution
- Timestamps for all segments
- Meeting chapters (if available)

### Sync Status

To check if sync is working:

1. Open PowerShell as Administrator
2. Run: `Get-ScheduledTaskInfo -TaskName "GranolaS3Sync"`
3. Check `LastRunTime` and `NextRunTime`

## Privacy & Security

### Data Storage

- **Local**: Granola cache on your Windows PC
- **Cloud**: AWS S3 bucket (private, encrypted)
- **Access**: Only you have the password

### Authentication

- Password-protected web interface
- Secure cookie-based sessions (7 days)
- HTTPS encryption in production

### Data Retention

- All meetings are kept indefinitely
- Backups created with each sync
- No automatic deletion

## Troubleshooting

### Can't Login

**Problem**: Password doesn't work

**Solution**:
1. Verify you're using the correct password
2. Clear browser cookies
3. Try incognito/private mode
4. Check Vercel logs for errors

### No Recent Meetings

**Problem**: New meetings not appearing

**Solution**:
1. Check sync is running: `Get-ScheduledTaskInfo -TaskName "GranolaS3Sync"`
2. View sync logs: `Get-Content granola-sync-service\sync.log -Tail 30`
3. Run manual sync: `.\sync-granola-to-s3.ps1 -RunOnce`

### Missing Transcripts

**Problem**: Meeting has no transcript

**Explanation**: Transcripts are ephemeral in Granola's local cache
- Only available during/after recording
- Granola deletes them after processing
- Hourly sync captures most transcripts

**Solution**: Transcripts captured depend on timing of sync

### Missing Summaries

**Problem**: Meeting has no AI summary

**Explanation**: Summaries come from Granola's API
- Only generated for completed meetings
- Requires Granola to process the meeting
- Not all meetings get summaries

**Solution**: Wait for Granola to generate summary, then sync will capture it

## Tips & Best Practices

### Maximize Transcript Capture

- Keep Granola running during meetings
- Let sync run hourly (don't disable)
- Transcripts are captured while Granola processes

### Search Effectively

- Use specific keywords
- Search by attendee names
- Filter by date range (coming soon)

### Review Summaries

- AI summaries highlight key points
- Check full transcript for details
- Summaries are in HTML format with sections

### Manage Storage

- Current structure scales to thousands of meetings
- Partitioned by year/month automatically
- Cost: ~$0.03/month for typical usage

## FAQ

**Q: How much does this cost?**
A: ~$0.03/month for S3 storage and operations

**Q: Can I access from mobile?**
A: Yes, the web interface is responsive

**Q: How long are sessions?**
A: 7 days, then you need to login again

**Q: Can I share meetings?**
A: Not currently, single-user only

**Q: What if I delete a meeting in Granola?**
A: It remains in your vault (not synced deletions)

**Q: Can I export meetings?**
A: Yes, download from S3 as JSON files

**Q: How do I change my password?**
A: Update `AUTH_PASSWORD` in Vercel environment variables
